# Aula_Erros_Debugging_Alexandre

## Sobre a atividade

Atividade prática de Tratamento de Erros e Avaliação de Soluções da disciplina **Pensamento Computacional** (UDF, 2026), ministrada pela Prof. Kadidja Valéria.

O objetivo é aplicar os conceitos de arquitetura da resiliência diretamente em um projeto real: identificar erros, corrigi-los com justificativa técnica e avaliar a qualidade da solução final.

---

## Projeto: Calculadora Matemática em Python

O projeto consiste em uma calculadora de operações básicas desenvolvida em Python, capaz de realizar:

- Soma, subtração, multiplicação e divisão
- Cálculo de porcentagem
- Validação de entradas do usuário

## Como executar o projeto

1. Certifique-se de ter o Python 3.x instalado
2. Clone o repositório: `git clone https://github.com/Alexandre-Matias/Pensamento_Computacional`
3. Execute o arquivo principal: `python calculadora.py`
4. Siga as instruções no terminal para realizar os cálculos
